# Provenance

All source, fixture text, plan examples, interface copy, and architecture documents were created for this standalone portfolio project. No private repository, employer system, customer log, credential, proprietary document, or copied company implementation was used.

The `search-index` service, incident counters, tickets, roles, tenants, and action text are synthetic. Ticket identifiers are generated during execution. The observed fault report is generated by executing `scripts/evaluate.mjs`; it records actual local results for that synthetic system and does not claim a general benchmark or production result.

The planner is deterministic. There are no model weights, model inference, hidden API calls, embeddings, or fabricated AI evaluation scores in this project.

Dependencies are pinned in `package.json` and `package-lock.json`:

- `@noble/hashes`: SHA-256 implementation used by both environments.
- TypeScript, esbuild, Prettier, and Node type declarations: build/type/format tooling.
- `fake-indexeddb`: adapter contract tests only; the browser demo uses the native API.
- Node `node:sqlite`: built-in SQLite adapter and separate synthetic external store.

References consulted:

- [Node.js SQLite API documentation](https://nodejs.org/api/sqlite.html).
- [SQLite transaction documentation](https://www.sqlite.org/lang_transaction.html).
- [IndexedDB API documentation](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API).

The implementation makes no association with any prospective employer or other organization. The public demo is linked solely for independent technical review.
